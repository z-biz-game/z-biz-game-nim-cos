战役 每日一题

    玩法：每步只能动一堆

    目标：把最后那枚棋子按本关选定的规则拿走或留给自己。对手不是「很强」而是完美玩家——它每步直接取闭式给出的第一个必胜着，没有让它变笨的开关。所以局面一旦交回 P 位（全体堆大小异或为 0），这局就已经不属于你了。

    规则只有一条：每一步只能动一堆，必须至少拿走一枚，而且不许跨堆拿。js/core/heaps.js 的文件头自己就是这么写的：「That is the entire rule book」。本仓其余代码要么是关于这个数组的定理（bouton.js），要么是对它的搜索（retro.js），要么只是像素。

    两种胜负约定，开局前在上方切换，同一套引擎用 rule 字段区分，不是两套引擎（NORMAL / MISERE，js/core/heaps.js）：

    • 取最后一枚者胜（normal）——拿走最后一枚的人赢。
    • 取最后一枚者负（misere）——拿走最后一枚的人输，要把最后一枚留给对手。

    胜负由 js/core/game.js:45 判：winner = rule === NORMAL ? mover : other(mover)，也就是「取最后一枚」在 misere 下会把胜者判给对手。

    怎么操作：先点一堆选中它，再点一条虚线框，把这堆剩成框上的那个数。跨堆点击不算棋，取 0 枚也不算。键盘：Esc 取消选中，U 回退一手，R 重开，直接敲数字键选数。

    屏幕上每个数字都是量出来的：outcome 是 Bouton 的闭式判定（异或为 0 即后手必胜），par 是双方各按最优取向时的总步数，winMoves 是本步的必胜着法数。
